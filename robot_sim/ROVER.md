# Мини-ровер в Gazebo — 29 октября 2026

Модель собрана из переданного rover_urdf. Исходные rover_urdf/ и mujoco_scene/
не изменяются. Это приблизительная физическая модель учебного мини-ровера,
а не откалиброванный цифровой двойник полноразмерного доставщика.

## Размеры и масса

Сохранены единицы и масштаб URDF: метры, килограммы, радианы.
Масса 0.500 кг, корпус 0.410 кг, шесть колёс по 0.015 кг.
Корпус collision-box 166.786 × 112.859 × 123.307 мм.
Колея 115.356 мм; ширина колеса 16.256 мм.
Радиус центральных колёс 22.124 мм, крайних 21.124 мм.
Габарит по наружным сторонам колёс около 131.612 мм.
Визуальная высота с флажком около 272 мм от земли.
Положение основания при спавне: 22.624 мм, после оседания около 22.124 мм.

Выбран URDF как единый источник геометрии. Приложенная старая MuJoCo-сцена
имеет другую колею 127.196 мм и не смешивается с этим описанием.

## Физика и допущения

- DART, шаг 1 мс, гравитация 9.81 м/с².
- Сохранены исходные массы, центры масс и тензоры инерции.
- Жёсткое шасси, фиксированные оси, подвеска отсутствует.
- Ведущие только центральные колёса; четыре крайних свободные, без моторов.
- Контакты колёс — цилиндры; корпус — исходный box; стойке добавлена
  приблизительная collision-геометрия без удвоения массы.
- Для ведущих колёс трение 0.9, для пассивных 0.01 — исходный экспериментальный
  пресет. Низкое трение крайних колёс облегчает боковое скольжение при развороте
  жёсткого шестиколёсного шасси. Это не измеренные свойства шин.
- Сохранена исходная разница радиусов 1 мм. Она слегка наклоняет шасси на ровном
  полу (в испытании около 1.08°). Подвеска не выдумывается.
- Два штатных Gazebo JointController в force mode: выход ±0.03 Н·м,
  velocity P=0.02, I=0.03, ограничение интегральной составляющей ±0.003.
  Режим прямого навязывания скорости колёсам не используется.
- Ограничения платформы: вперёд 0.20 м/с, назад 0.12 м/с,
  поворот 1.0 рад/с, разгон 0.30 м/с², торможение 0.50 м/с².
- Остановка при отсутствии команд или состояний колёс более 0.6 с
  реального времени. Сам Gazebo продолжает физическое торможение.
- Одометрия вычисляется из фактических углов двух ведущих колёс.
  Ground truth используется только в проверке и записи результатов.

Предел момента проверяется по конфигурации штатного force PID. В используемой
связке JointState effort публикуется нулевым: эти нули не являются измерением
реального момента двигателя.

## Визуальная модель и сенсоры

Сохранены меши, UV и цветовые текстуры. В сгенерированных OBJ добавлены нормали,
которых не было в исходных файлах; без них Ogre2 не отображал материалы.
Исходные OBJ не перезаписываются.

Добавлены виртуальные сенсоры с явно выбранными, не измеренными параметрами:
- передняя RGB-камера 320×240, 100° по горизонтали, 5 Гц;
- 360° лидар, 360 лучей, 10 Гц, 0.025–10 м, шум 2 мм;
- IMU 50 Гц, идеальные показания без калибровки под реальную IMU;
- датчик контакта корпуса и стойки;
- внешняя следящая камера 640×480, 3 Гц для записи настоящего изображения Gazebo.

Все позы сенсоров и physics-настройки записаны в
robot_sim/models/yandex_rover/specification.json. TF публикуется из того же
описания геометрии. Внешняя камера предназначена для просмотра, не для LLM.

## Запуск на сервере

Из /home/motovilovil/async_llm/async_llm:

```bash
# Скриптовая проверка: вперёд, назад, оба поворота, дуга, торможение, watchdog.
bash robot_sim/scripts/run_rover.sh

# Отдельный проезд на прежней складской сцене.
bash robot_sim/scripts/run_rover.sh --scene warehouse --motion-case forward

# Контакт с препятствием и небольшой порог — отдельные испытания.
bash robot_sim/scripts/run_rover.sh --motion-case contact
bash robot_sim/scripts/run_rover.sh --motion-case step

# Интерактивное окно Gazebo через существующий noVNC viewer.
bash robot_sim/scripts/run_gui.sh warehouse --robot rover
# Для старой модели: ... warehouse --robot burger
```

Viewer слушает только 127.0.0.1:17080. На своём компьютере открыть SSH-туннель:
`ssh -N -L 17080:127.0.0.1:17080 185.185.59.19`, затем
http://127.0.0.1:17080/vnc.html . Пароль текущего сеанса находится на сервере
в robot_sim/.runtime/viewer/session/password.
Для приближения в дереве Gazebo выбрать yandex_rover и нажать F.

В другом серверном терминале можно подавать команды в активный viewer:
```bash
source robot_sim/scripts/robot_env.sh
ros2 topic pub -r 10 /cmd_vel geometry_msgs/msg/Twist '{linear: {x: 0.10}, angular: {z: 0.0}}'
```
После Ctrl+C контроллер остановится по watchdog. Только один управляющий запуск
должен работать в ROS_DOMAIN_ID=73 одновременно. Для параллельных сеансов задавайте
разные ROS_DOMAIN_ID до запуска. Газебо-сессии уже разделены GZ_PARTITION.

Просмотр статического мира без контроллера возможен через
`gz sim robot_sim/worlds/rover_warehouse.sdf` после robot_env.sh,
но в этом варианте колёса не получают команд.

## Существующий LLM/Nav2 runtime

Для выбора модели добавлен --robot rover; старый --robot burger сохранён.
Пример прямого управления из существующего LLM-worker:

```bash
bash robot_sim/scripts/run_navigation.sh --robot rover --scene warehouse \
  --mode direct --task-file robot_sim/direct_tasks/left_turn_state_v2.json
```

Worker Qwen должен быть отдельно запущен. В рамках переноса модели Qwen не
запускался; качество LLM на новом ровере пока не оценено.
Для Nav2 автоматически подставляются размеры footprint и TF новой модели.
Полноценный прогон Nav2 на ровере пока не является частью выполненной проверки.

## Сборка и проверка

```bash
source robot_sim/scripts/robot_env.sh
python -m robot_sim.rover
python -m unittest discover -s robot_sim/tests -v
```

Не оборачивайте unittest дополнительно в robot_sim.resource_limits:
проверка самого ограничения CPU создаёт такой дочерний процесс самостоятельно.
Обычные скрипты запуска уже применяют taskset и наследуемый seccomp-фильтр:
все потоки работают на одном логическом CPU, рендеринг Mesa llvmpipe, 0 GPU.

Сгенерированные модели и миры:
- robot_sim/models/yandex_rover/model.sdf, robot.urdf, meshes/, specification.json
- robot_sim/worlds/rover_lab.sdf — свободная зона, калибровочные ящики, порог 5 мм
- robot_sim/worlds/rover_warehouse.sdf
- robot_sim/worlds/rover_apartment.sdf
- robot_sim/worlds/rover_courtyard.sdf

Сцены Burger и результаты прежних экспериментов сохранены.
Проверки на ровном полу не подтверждают проходимость бордюров, снег, рыхлый грунт,
характеристики подвески или точный перенос на физический мини-ровер.
