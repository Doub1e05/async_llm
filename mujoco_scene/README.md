# Сцена MuJoCo — робот-доставщик

Самостоятельная папка: XML, меши и скрипт запуска. Можно переносить целиком.
Масса 500 г, шесть колёс с фиксированными осями, два центральных — ведущие.

## Запуск на этом компьютере

Из этой папки:

```bash
../robot_model/.venv/bin/mjpython run.py
# Движение вперёд со скоростью 0,1 м/с:
../robot_model/.venv/bin/mjpython run.py --linear 0.1
```

## Запуск после переноса

Создать окружение и установить зависимости (Python 3.13):

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
# macOS:
.venv/bin/mjpython run.py
# Linux:
.venv/bin/python run.py
```

Также можно открыть `delivery_robot.xml` в MuJoCo Viewer. Папка `meshes` должна оставаться рядом с XML.
`run.py --linear V --angular W` задаёт линейную скорость в м/с и угловую в рад/с через два привода.

Радиус колёс — 0,021124 м, колея — 0,12719633 м. Все меши в метрах.
Масса задана пользователем; распределение массы, трение и параметры моторов оценочные.
С фиксированными осями разворот требует бокового скольжения: при текущем трении почти блокируется.
`parameters.json` используется скриптом для пересчёта команд скорости; физические параметры сцены заданы в XML. Изменение JSON не перестраивает XML автоматически.
